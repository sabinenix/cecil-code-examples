# Code Example: Export a GeoTIFF file

This subdirectory contains example code for creating a raster file and saving it as a GeoTIFF. The code will demonstrate how to export a GeoTIFF from both a simple single polygon AOI, and walk through how to adjust the process for exporting a GeoTIFF from a MultiPolygon AOI.

The example code is included in a Jupyter Notebook (`export-geotiff.ipynb`).
